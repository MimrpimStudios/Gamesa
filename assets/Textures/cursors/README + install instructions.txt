Simple Pixel Cursors .cur + .ani - Install Instructions

═══════════════════════════════════════════════

To use these cursor files as your actual Windows cursor you have
2 Options: 

* Choose either the light or the dark cursor folder and locate 
  the included install(- dark/light).inf file. Right click and
  select install. 

* Go into Settings and search for Mouse. Then scroll untill you
  find "additional Mouse Options". In the Mouse properties select
  the pointers tab, here you will be able to Change all your
  Cursors to the desired ones.

To get your default cursor back or select other Cursors locate 
the Mouse properties Settings like in Option 2 and under
Scheme you can select the desired Scheme.
